# Football Ground Attack Lab

Customizable running-back drill on a single HTML5 canvas.

Open `index.html` in any modern browser (or host via GitHub Pages).

Under active development.

Not affiliated with, endorsed by, or licensed by any league or team.

## Features

1. Scripted play steps (dive, blast, sweep, counter) with pre-snap arrows
2. Zone-aware defense with chase angles
3. Offense–Defense tilt
4. Expanded keyboard controls (speed burst, truck)
5. Side-by-side formation, team, and config panel
6. 14 teams
7. Adjustable number of OL, FB, LB, and DB
8. Adjustable session length
9. Variable field width
10. Post-touchdown LOS logic (incremental with customizable start and increment, or randomized with customizable range)
11. Field goal posts and corner pylons
12. Mountain endzone pattern, midfield Elevation Edge logo

## Controls

| Action        | Key          |
|---------------|--------------|
| Move          | WASD / Arrows|
| Speed burst   | Space        |
| Truck         | V / Y        |

## Defaults

- Field width: 50 yards  
- Time: 1 minute  
- OL 2 · FB 2 · LB 2 · DB 3

## Tech

Single-file HTML + Canvas + JavaScript. No dependencies. Works offline.
